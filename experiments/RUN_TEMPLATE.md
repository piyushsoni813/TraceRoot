# Experiment run template

Create `input/` and `output/` directories for each run. Store the exact prompt and only the approved bug report and stack trace under `input/`. Keep reference fixes out of the experiment directory and model context.

Record the model name/version, run date, decoding settings, case ID, input file hashes, and the unedited response. Record evaluation criteria and observed evidence in `evaluation.json`; distinguish observed results from interpretation.
